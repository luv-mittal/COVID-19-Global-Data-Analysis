# luv-mittal-COVID-19-Global-Data-Analysis-ON-SQL-Server-
This project explores the global impact of the COVID-19 pandemic using SQL Server, analyzing case counts, deaths, and vaccination data across 200+ countries from January 2020 to April 2021. The goal was to uncover meaningful trends in infection spread, mortality rates, and vaccine rollout speed through structured, query-driven data exploration.

Using the publicly available Our World in Data (OWID) COVID-19 dataset, I wrote a series of SQL queries to calculate key metrics such as death percentages, infection rates relative to population, and rolling vaccination totals over time. The project makes use of joins, CTEs, temporary tables, window functions, and views to transform raw time-series data into clear, comparable insights at the country and continent level.
Data Source https://ourworldindata.org/covid-deaths
Key questions explored in this project include:

Which countries had the highest infection and death rates relative to population?
How did vaccination rollout progress over time, and which countries adopted vaccines earliest?
How do continents compare in terms of total death counts and pandemic severity?
What percentage of each country's population had been vaccinated by a given date?
