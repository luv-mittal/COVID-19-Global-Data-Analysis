This project analyzes COVID-19 cases, deaths, population infection rates, vaccination levels, and demographic factors using SQL, Excel, and Tableau.

The project follows an end-to-end data analytics workflow where I first used SQL Server to extract and transform the required data, exported the query results to Excel, and then connected the processed results to Tableau to create interactive dashboards and visualizations.

The main objective was to explore the spread and impact of COVID-19 across different countries and continents and understand how infection rates, deaths, vaccination levels, and demographic factors varied across locations.

Dashboard 1 – COVID-19 Global Overview

The first dashboard provides an overview of the global COVID-19 situation.

Visualizations include:

Total Cases
Total Deaths
Death Percentage
Total Deaths by Continent
Percentage of Population Infected by Country
Infection Trends Over Time
Country-level filtering

The dashboard allows users to explore differences in COVID-19 infection rates and deaths across countries.

Dashboard 2 – Vaccination & COVID-19 Analysis

The second dashboard focuses on vaccination and its relationship with COVID-19 outcomes.

Visualizations include:

Number of People Fully Vaccinated
Monthly Deaths vs. Fully Vaccinated Population
Percentage of Population Fully Vaccinated
Age 65+ vs. Total Deaths
Geographic distribution of vaccination rates

The dashboard helps explore patterns between vaccination levels, deaths, and demographic characteristics. The vaccination/death comparison is exploratory and does not by itself establish a causal relationship.
